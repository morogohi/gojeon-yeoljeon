# 요구사항별 합격 기준과 연결 테스트

기능 설명은 [product-spec.md](product-spec.md). 이 표의 **마지막 열(연결 테스트)** 은 자동화가 읽는다(`scripts/qa/lib.mjs` `parseRequirements`). 테스트 ID는 테스트 제목 맨 앞에 있다(`U-` 엔진, `C-` 콘텐츠, `F-` 기능 단위, `E-` E2E, `L-` 화면 폭, `R-` 회복력, `Q-` 자동화).

규칙
- 요구사항마다 연결 테스트가 1개 이상 있어야 한다(Q-24가 검사). 테스트 ID를 지우거나 바꾸면 이 표도 같이 고친다 — 이 파일은 사람만 고친다.
- PASS는 연결 테스트가 모두 통과하고, Codex 보고서가 요구사항마다 증거를 낸 경우에만 준다.
