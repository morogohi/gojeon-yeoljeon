# 고전열전(古典列傳) 제품 명세 — 공통 기준

이 문서는 사람·Claude·Codex가 함께 보는 **단일 기준**이다. 기능의 목적과 범위는 여기에, 요구사항별 합격 기준과 연결 테스트는 [requirements.md](requirements.md)에 둔다. 다른 문서는 요구사항을 다시 적지 않고 ID로만 가리킨다.

> 출처: 상세 설계 문서(v0.2–v0.7.1)는 저장소 밖(Claude Docs)에 있다. 저장소 안에서는 이 문서와 requirements.md가 기준이며, 둘이 설계 문서와 다르면 사용자에게 확인한다.

## 1. 제품

- 사기(史記)·논어(論語)의 고사를 장면으로 읽고, 한자·고사성어 문제로 전투하며 익히는 모바일 학습 게임.
- 대상: 초등 고학년·중학생과 보호자. 약속: "하루 10분, 이야기로 고사성어 하나를 익혀요".
- 배포: 웹 `https://morogohi.github.io/gojeon-yeoljeon/`(홍보·안내) 와 `/play/`(게임), Android(AAB), iOS(Codemagic → TestFlight). 앱은 같은 웹 빌드를 Capacitor로 감싼다.
- 서버 없음. 학습 기록은 기기 저장소(localStorage, 버전 1)에만 둔다. 분석 전송은 `VITE_ANALYTICS_URL`이 있을 때만.

## 3. 고정된 결정

- 라우팅은 해시(`#name-arg`). 서버 경로 재작성이 없는 GitHub Pages 하위 경로에서 동작해야 한다.
- 테스트 모드: `?e2e=1`이면 난수 시드 12345, `&today=YYYY-MM-DD`로 날짜 고정.
- 한자 수 표기는 "익힌 한자"로 통일(결과 화면은 "이번 고사에서 만난 한자").
- 문구·학습 내용 변경, 저장 형식 버전 변경, 외부 전송 추가는 사용자 결정 사항이다(자동 수정 대상 아님).
